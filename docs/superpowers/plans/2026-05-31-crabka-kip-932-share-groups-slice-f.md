## Established facts (verbatim from research — file:line)
- **`share_partition/state.rs`** `AcquisitionState`: private `delivery_complete_count: i32`; `acknowledge(member, first, last, AckType, now)->Result<(),i16>` guards `range_acquired_by(member,first,last)` else `crate::codes::INVALID_RECORD_STATE`, splits at `first`/`last+1`, sets state, `self.dirty=true; self.advance_spso()`. `expire_locks(now)` reverts Acquired→Available past `lock_deadline`. `materialize(hwm:i64, max_inflight:i32)` early-returns if any Available or `end_offset>=hwm`, else appends Available `[end_offset, (hwm-1).min(end_offset+max_inflight-1)]`. `to_persist_batches()->(i64 start, i32 dcc, Vec<StateBatch>)`. **`load_from(start_offset, state_epoch, leader_epoch, &[StateBatch])` line ~431 hardcodes `self.delivery_complete_count = 0;` (line 442)** and maps persisted Acquired(1)→Available. `range_acquired_by`, `split_at_offset` exist (used by `acknowledge`).
- **`share_fetch.rs`**: `acquire_pass` — `st.expire_locks(now); let hwm = part.high_watermark().await; st.materialize(hwm, cfg.max_inflight_records); let acquired = st.acquire(member, max_records, max_bytes, now, cfg.record_lock_duration, cfg.max_delivery_attempts);`. Read: `let (first,last)=acquired_span(&acquired); let limit=(last+1).min(hwm); let read_budget = if p.partition_max_bytes>0 {..} else {max_bytes}; let bytes = read_acquired_bytes(&part, first, limit, read_budget).await?; p.out.records = bytes.map(RecordsPayload::Raw); p.out.acquired_records = acquired.iter().map(|r| AcquiredRecords{first_offset,last_offset,delivery_count,..Default::default()}).collect();`. `acquired_span(&[AcquiredRange])->(i64,i64)` = (min first, max last). `read_acquired_bytes(part, fetch_offset, limit_offset, max_bytes:i32)->Result<Option<Bytes>,BrokerError>` = `spawn_blocking(|| log.lock().read_raw(fetch_offset, limit_offset, read_max))`, returns `Some(raw.bytes)` if `raw.total>0`. Piggyback: `apply_one_ack(&mut st, member, first, last, types:&[i8], now)->Result<(),i16>` (pub(crate); empty types → Accept; else coalesces equal-typed runs → `st.acknowledge`). The handler does NOT read `req.is_renew_ack` and passes no isolation level. `RawRead { bytes, total }`.
- **`fetch.rs` do_read** read_committed: `let read_committed = !is_follower_fetch && req.isolation_level == 1;` `effective_lso = if read_committed && !is_follower_fetch { lso.min(hw) } else { lso };` read `limit_offset = if read_committed { effective_lso } else { hw }`; aborted walk inside the read `spawn_blocking`: `log.aborted_in_range(fetch_offset, effective_lso)` → `Vec<AbortedTxn{producer_id, start_offset}>` → `AbortedTransaction{producer_id, first_offset: start_offset}`. Accessors: `Partition::lso()->i64` (partition.rs:204), `Partition::aborted_in_range(start,end)->Vec<AbortedTxn>` (partition.rs:347).
- **`share_acknowledge.rs`**: reuses `apply_one_ack`; ignores `req.is_renew_ack` (exists on wire). Loop: `let cell = mgr.get_or_load(&group, topic_id, ap.partition_index).await; let mut st = cell.lock().await; for batch in &ap.acknowledgement_batches { apply_one_ack(&mut st, &member, batch.first_offset, batch.last_offset, &batch.acknowledge_types, now) } ; mgr.persist_if_dirty(...).await`.
- **`manager.rs`**: `persist_if_dirty(group, topic_id, partition, st: &mut AcquisitionState)` — `if !st.dirty {return}; let (start,dcc,batches)=st.to_persist_batches(); if let Err(e)=self.persister.write_state(group,topic_id,partition,st.state_epoch,st.leader_epoch,start,dcc,batches).await { warn!(...) } st.dirty=false;` **(`st.dirty=false` is OUTSIDE the Err block — line ~247).** `get_or_load`: on miss `read_state` → `st.load_from(persisted.start_offset, persisted.state_epoch, leader_epoch, &persisted.state_batches)` (persisted is `share_coordinator::state::SharePartitionState` which HAS `delivery_complete_count`). `spawn_lock_sweeper` ticks `record_lock_duration/2`, snapshots cells, `expire_locks` + `persist_if_dirty`.
- **`share/config.rs`** `ShareGroupConfig` has `record_lock_duration: Duration, max_delivery_attempts: i16, max_inflight_records: i32` (+ session fields). NO `isolation_level`. Unit test `slice_c_defaults`.
- **`share/actor.rs`**: `ShareGroupActorMessage { Heartbeat{..}, Describe{reply}, Seed(..), Shutdown(..) }`; `ShareGroupActorHandle { pub tx: mpsc::Sender<ShareGroupActorMessage>, .. }`. v14 persist: `PendingShareRecords { .., state_partition_metadata: Option<ShareGroupStatePartitionMetadataValue> }` → `into_batch` writes `ShareGroupKey::StatePartitionMetadata` → `flush_pending(state, pending, offsets_log, coordinator, now_ms)` (appends + `coordinator.update_share_cache`). `state.initialized: HashSet<(Uuid,i32)>`. `state_partition_metadata_from(state)->ShareGroupStatePartitionMetadataValue`. Pattern (from `reconcile_share_state`): `let pending = PendingShareRecords { state_partition_metadata: Some(state_partition_metadata_from(state)), ..Default::default() }; flush_pending(state, pending, offsets_log, coordinator, now_ms).await`.

- **Client `client-consumer/src/share/`**: `ShareAckType {Accept,Release,Reject}` + `wire()->i8` (1/2/3). `is_renew_ack: false` hardcoded at poll.rs:118 (ShareFetch) + poll.rs:270 (ShareAcknowledge in `flush_pending_acks`). `acknowledge(&mut self, record, ack)` errors `IllegalState` in Implicit mode else pushes to `pending_acks`. `commit()`→`flush_pending_acks` sends standalone `ShareAcknowledgeRequest`.
- **Wire**: `ShareFetchResponse...PartitionData { records: Option<RecordsPayload>, acquired_records: Vec<AcquiredRecords{first_offset,last_offset,delivery_count}> }`. `is_renew_ack: bool` on both ShareFetchRequest + ShareAcknowledgeRequest. `RecordsPayload::{V2,Raw,Legacy}`.

## Task F-fetch (F1-handlers, F2, F5)
**Files:** `handlers/share_fetch.rs`, `handlers/share_acknowledge.rs`.

- [ ] **F1 (renew routing):** in both handlers, if `req.is_renew_ack`, route each ack batch `(first,last,_types)` to `st.renew(member, first, last, now, cfg.record_lock_duration)` instead of `apply_one_ack`; set `acknowledge_error_code` (ShareFetch) / `error_code` (ShareAcknowledge) from the result. (cfg = `broker.config.share_group`.)
- [ ] **F2 (read_committed):** compute `let read_committed = matches!(cfg.isolation_level, ShareIsolationLevel::ReadCommitted);` In `acquire_pass`: `let hwm = part.high_watermark().await; let upper = if read_committed { part.lso().min(hwm) } else { hwm }; st.materialize(upper, cfg.max_inflight_records);` and use `upper` as the read `limit` clamp (`(last+1).min(upper)`). **Aborted records:** when read_committed, after materialize, archive aborted offsets: query `part.aborted_in_range(st.start_offset, upper)` and for each aborted txn range mark those offsets `Archived` in `st` so they aren't acquired (add an `AcquisitionState::archive_range(first,last)` helper, or skip aborted offsets in `acquire`). IF the precise abort-range→offset mapping is hard (aborted txns give producer_id + start_offset, not exact end), ship the **LSO clamp alone** (correct "no uncommitted records") and add a `// TODO(slice-F): archive aborted records within committed range` + note it in the commit/report. Prefer correctness over completeness; the LSO clamp is the must-have.
- [ ] **F5 (per-range concat):** replace the single `read_acquired_bytes` over `[min_first, max_last+1)` with one read per acquired `AcquiredRange` (clamped to `upper`), concatenating the `Bytes` into a single `BytesMut` → `RecordsPayload::Raw`. (Contiguous ranges still produce one logical blob; gaps are excluded.) Keep `acquired_records` as the authoritative list.
- [ ] Build; `cargo test -p crabka-broker --test share_consume` (no regressions); clippy. Commit `feat(kip-932): ShareFetch renew + read_committed + per-range record reads`.
