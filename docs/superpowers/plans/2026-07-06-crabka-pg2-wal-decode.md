# PG-2: Postgres WAL decode + page-shard — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new sans-IO crate `crabka-postgres-wal` that decodes Postgres 17 physical WAL (segment/page framing, contrecords, CRC-32C, block refs, FPIs with hole reconstruction) and shards decoded records by `(RelTag, block) @ LSN`, verified line-for-line against committed `pg_waldump` output.

**Architecture:** A pull parser (`feed(lsn, bytes)` / `poll_record()`) with internal contrecord buffering; a pure `shard_record` fan-out. Fixtures are real 1 MB WAL segments generated once from stock Postgres 17 and committed with their `pg_waldump` oracle text — CI is hermetic (no Postgres).

**Tech Stack:** Rust 2024 (pinned stable 1.96.0), `bytes`, `thiserror`, CRC-32C (reuse `crabka-protocol`'s if exported, else the `crc32c` crate), **no tokio**, `assert2`/`nextest`, `cargo +nightly fmt`, `clippy::pedantic`.

**Spec:** [`docs/superpowers/specs/2026-07-06-crabka-pg2-wal-decode-design.md`](../specs/2026-07-06-crabka-pg2-wal-decode-design.md).

**PREREQUISITES:** none — no unbuilt Crabka code; fixture generation needs a local Postgres 17 once.

---

## Invariants

1. **Byte-faithful:** accept exactly what PG 17 emits; fixture bytes are always generated by real Postgres, never hand-crafted.
2. **rmgr-agnostic:** decode the envelope (xid/rmid/info/block-refs/images/data) for every rmgr; never interpret payloads (redo = PG-4).
3. **Sans-IO:** no I/O, no tokio; LSN-addressed `feed`/`poll_record` only.
4. **Loud failures:** wrong magic → versioned error; CRC mismatch → error with LSN; compressed FPI → documented rejection; truncated tail → "incomplete", never a panic.
5. **Differential gate:** the committed-fixture parse matches the committed `pg_waldump` oracle line-for-line before shipping.
6. **New-crate hygiene:** `publish = false` + a private release-plz entry (`./tools/check-publish-allowlist.sh` green).
7. **Every task ends green** before its commit.

## Scope boundary

- **In scope:** the fixture corpus + generation script; `Lsn`; page framing; record assembly (contrecords + CRC); body grammar (block refs, `SAME_REL`, FPI holes, data headers); the shard router; the differential gate.
- **Deferred:** compressed FPIs (pglz/lz4/zstd — rejected loudly); redo (PG-4); live replication ingest (PG-1); PG ≠ 17 majors; layer storage (PG-3).

## Task 1: Fixture corpus + generation script

**Files:**
- Create: `tools/gen-pg-wal-fixtures.sh`, `crates/postgres-wal/tests/fixtures/{*.wal,oracle.waldump,manifest.toml}`

- [ ] **Step 1: Write the generator**

```bash
#!/usr/bin/env bash
# Generates the committed PG-17 WAL fixture corpus. Requires a local Postgres 17
# (initdb/pg_ctl/psql/pg_waldump on PATH). Re-run only to extend the corpus.
set -euo pipefail
D=$(mktemp -d); trap 'pg_ctl -D "$D/data" stop -m immediate || true; rm -rf "$D"' EXIT
initdb -D "$D/data" --wal-segsize=1 >/dev/null           # 1 MB segments (small, committable)
cat >>"$D/data/postgresql.conf" <<EOF
wal_level = replica
wal_compression = off
max_wal_senders = 0
EOF
pg_ctl -D "$D/data" -l "$D/log" -o "-p 54329 -k $D" start >/dev/null
P="psql -h $D -p 54329 -d postgres -qAt -c"
$P "CREATE TABLE t(id bigserial PRIMARY KEY, pad text);"
$P "INSERT INTO t(pad) SELECT repeat('x', 500) FROM generate_series(1, 3000);"   # multi-page + index splits
$P "UPDATE t SET pad = repeat('y', 500) WHERE id % 7 = 0;"
$P "DELETE FROM t WHERE id % 11 = 0;"
$P "INSERT INTO t(pad) VALUES (repeat('z', 900000));"    # TOAST + a record run crossing the 1 MB segment boundary
$P "CHECKPOINT;"                                          # FPIs after checkpoint on next touches
$P "UPDATE t SET pad = 'post-ckpt' WHERE id = 1;"
$P "SELECT pg_switch_wal();"
OUT=crates/postgres-wal/tests/fixtures
mkdir -p "$OUT"
# Copy every completed segment + the oracle text; record the environment.
cp "$D"/data/pg_wal/0000000100000000000000* "$OUT"/ 2>/dev/null || true
ls "$OUT" | grep -v -e oracle -e manifest | sort | head -n 4 > "$D/keep"   # keep a bounded corpus
find "$OUT" -maxdepth 1 -name '0*' | sort | tail -n +5 | xargs -r rm
pg_waldump "$OUT"/$(ls "$OUT" | grep '^0' | sort | head -1) "$OUT"/$(ls "$OUT" | grep '^0' | sort | tail -1) > "$OUT/oracle.waldump" || true
printf 'pg_major = 17\nwal_segsize = "1MB"\nwal_compression = "off"\nplatform = "little-endian"\n' > "$OUT/manifest.toml"
echo "fixtures written to $OUT"
```

- [ ] **Step 2: Implement**

Body walk (all LE): repeat block headers while `id <= 32` — `XLogRecordBlockHeader { id:u8, fork_flags:u8, data_length:u16 }` (`fork = fork_flags & 0x0F`; flags `HAS_IMAGE 0x10, HAS_DATA 0x20, WILL_INIT 0x40, SAME_REL 0x80`); if `HAS_IMAGE`: `XLogRecordBlockImageHeader { length:u16, hole_offset:u16, bimg_info:u8 }` (`HAS_HOLE 0x01, APPLY 0x02`; compression bits `0x04|0x08|0x10` → the loud rejection); if `!SAME_REL`: `RelFileLocator { spc_oid:u32, db_oid:u32, rel_number:u32 }`; then `blkno:u32`.
