**Design:** `docs/superpowers/specs/2026-05-23-crabka-operator-oauth-tls-trust-50b-design.md`
**Umbrella:** `docs/superpowers/specs/2026-05-23-crabka-oauth-parity-roadmap-design.md`
**Paired core slice:** 49c (shipped). Broker accepts `[oauthbearer].jwks_tls_trust` PEM path.

**Goal:** Surface 49c's broker knob on the operator CRD as Strimzi-shaped `tlsTrustedCertificates`, build the trust bundle into a managed Kubernetes Secret, mount it into broker pods, render the broker TOML's `jwks_tls_trust` line, and upgrade the kind-oauth e2e from HTTP to HTTPS using Bitnami Keycloak's auto-generated TLS.

**Architecture:** Six batches; the slice flows leaf → consumers → tests → e2e → gate. CRD types are added in batch 1. Listener-level (TOML render, canonical-tuple) and reconciler-level (read source Secrets, concat, upsert managed Secret) work happens in parallel in batch 2 because the files are disjoint. Pod-template plumbing depends on the reconciler's `Option<String>` return value so it lands sequentially in batch 3. Integration tests + sample + CRD regen run in parallel in batch 4. E2E + final gate are batches 5 and 6.

**Tech stack:** kube-rs 3.x `CustomResource` + `Api<Secret>`, schemars 1.x, existing patch + apply helpers in `controller/common.rs`. No new crates. The e2e adds `keytool` import into the existing JKS truststore init step. Bitnami Keycloak chart `25.2.0` with `tls.enabled=true tls.autoGenerated=true`.

     ```rust
     /// Slice 50b. Build the managed oauth-jwks-trust Secret from the
     /// canonical OAuth config's `tls_trusted_certificates`. Returns
     /// the Secret's name (so the StatefulSet can mount it), or `None`
     /// when no managed Secret is needed (no trust certs configured).
     async fn reconcile_oauth_jwks_trust(
         secret_api: &Api<k8s_openapi::api::core::v1::Secret>,
         kafka: &Kafka,
         canonical: Option<&crate::crd::ListenerAuthenticationOAuth>,
     ) -> Result<Option<String>, ReconcileError> {
         let Some(canonical) = canonical else {
             return Ok(None);
         };
         if canonical.tls_trusted_certificates.is_empty() {
             return Ok(None);
         }
         let mut bundle = Vec::<u8>::new();
         for entry in &canonical.tls_trusted_certificates {
             let src = secret_api
                 .get_opt(&entry.secret_name)
                 .await?
                 .ok_or_else(|| {
                     ReconcileError::MissingOauthTrustSecret(entry.secret_name.clone())
                 })?;
             let key_bytes = src
                 .data
                 .as_ref()
                 .and_then(|d| d.get(&entry.certificate))
                 .ok_or_else(|| ReconcileError::MissingOauthTrustKey {
                     secret: entry.secret_name.clone(),
                     key: entry.certificate.clone(),
                 })?;
             if key_bytes.0.is_empty() {
                 return Err(ReconcileError::EmptyOauthTrustValue {
                     secret: entry.secret_name.clone(),
                     key: entry.certificate.clone(),
                 });
             }
             if !bundle.is_empty() && !bundle.ends_with(b"\n") {
                 bundle.push(b'\n');
             }
             bundle.extend_from_slice(&key_bytes.0);
         }
         let managed_name = format!("{}-oauth-jwks-trust", kafka.name_any());
         upsert_oauth_trust_secret(secret_api, kafka, &managed_name, bundle).await?;
         Ok(Some(managed_name))
     }
     ```
