Rust-oracle Connect envelope vectors for the C++ SDK pure codec.

Generated by `cargo run -p crabka-sdk-conformance --bin emit_cpp_codec_oracle_vectors -- sdks/cpp/test/vectors`.
The generator is the checked-in Rust oracle seam for Connect envelope framing: one flag byte,
a 32-bit big-endian payload length, and exact payload bytes. EndStream uses the Connect
end-stream flag (0x02), not the gRPC-Web trailer flag (0x80). C++ tests must consume
these bytes rather than reconstructing expected frames inline.

message_payload_pay.hex: single uncompressed message frame with payload `pay`
compressed_payload_pay.hex: single compressed-bit message frame with payload `pay`
multi_frame_stream.hex: two message frames, `one` then `two`
partial_header.hex: truncated three-byte prefix for NeedMore coverage
endstream_clean.hex: clean Connect EndStream frame with empty payload
endstream_not_found.hex: Connect EndStream frame carrying `{"error":{"code":"not_found","message":"missing"}}`
